Sources

Built-ins + HTTP plugins behind one trait (search · item · capabilities · browse). Circuit breaker + live telemetry per source drive ranking automatically.

Search

/api/search/all fans out in parallel, merges duplicate titles across sources into one card listing every contributor, ranks by relevance.

Failover

Playback breaks? Ranked fallbacks take over — or the resolver retries other sources by title. The client just presses play again.

Security, end to end

Every playback authorization passes through one controller. Risk layer off by default — admins tune it.

Risk gate

Signals → score → decision:

allowproceed
challenge403 until acknowledged
revokeblocked, audited

Sessions · devices · resolves/h · distinct TLS fingerprints · prior flags.

Fingerprint-bound grants

Grants bind to the client's TLS context (edge sends X-JA4). Stolen token + different stack = 403 mismatch.

HMAC-SHA256 · TTL 600 s · instant revocation.

Segment scopes

Parent grant mints child tickets scoped to seg:N, ≤120 s. Initial access authorizes one segment — not the whole file.

Keys · watermark · origin

AES-256-GCM key hierarchy, HLS AES-128 via grant-gated endpoint. Every URL carries wm=… — leaks trace to one session. CDN-only origin via X-Origin-Token.

Offline playback — 24 h keys

POST /api/playback/offline-keys → content key delivered once over TLS, bound to user + media + device. Client stores it in OS keystore (Keychain / DPAPI / Keystore). After 24 h the next playback window needs a fresh license — key rotation kills old downloads permanently.

The rest of the platform

Media graph

12 relation types link any format — manga ↔ anime ↔ novel ↔ film. /journey traverses franchises; /discover/journeys suggests the story format you haven't tried.

Universal progress

Seconds for video/audio, pages+% for books/manga — one shape, one rail: GET /api/continue across every type.

Realtime

Event bus persists everything notable and bridges it onto /ws. Heartbeats reap dead sockets; personal rooms deliver notifications privately.

AI copilot

Admin console brain: heuristic rules or your own LLM endpoint. Autonomy dial: observe → suggest → act. Whitelisted actions only, fully audited.

Self-running ops

5xx timeline with AI spike alerts. Duplicates auto-merge. Cache warmer precomputes rails before demand. Analytics age into aggregates.

Personal twin

Behavioral model per user — genres, formats, completion, pace, discovery appetite — powering ranking and rails. Snapshotted daily.
